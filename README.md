# Investigation Workflow Studio — booth demo

Two files, kept in the same folder:

| File | What it is |
|---|---|
| `investigation-workflow-studio.html` | The demo. Open it in Chrome or Edge; it works offline. |
| `booth-config.js` | Booth defaults: risk bands and how each case starts. Edit it in any text editor, save, and reload the page. |

If `booth-config.js` is missing or a value in it is invalid, the demo uses its built-in defaults.

- Public view: open the HTML file as is.
- Editor: add `?studio` to the address, or press **Ctrl+Shift+E**.
